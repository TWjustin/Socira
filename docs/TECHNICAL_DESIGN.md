- 土地擁有者離線時，土地與相關功能是否可用，以及預期行為。
- 資料修改權限、可信來源、防竄改與備份方式。
- 跨土地交易的完成條件、重複操作、失敗中斷及資料衝突處理。
- 公司紀錄與所在地資料之間的關係及可用性。
- 多人連線、同步與權威端配置。
- 聊天架構。
- 後續功能需要擴充的存檔內容，以及長期格式、相容性、備份與失敗復原方案。

首版儲存時機、角色位置與鏡頭方向的保存及重進恢復需求已確認，詳見 [遊戲設計](GAME_DESIGN.md)。ConfigFile 是目前原型已採用的實作格式，不代表長期格式已由使用者定案；既有原型仍需執行驗證。

以上是評估問題，不是新增玩法或選定解法。實作前須先確認需求，再以小範圍原型測試可行性。
